# Reporting Bugs and Submitting Feature Requests

Please report bugs and request features on the module's GitHub issue tracker:

<https://github.com/foundryvtt-dcc/xcc/issues>

When reporting a bug, please include:

* The XCC module version and the DCC system version (both are shown in **Manage Modules** / **Game Details**).
* Your Foundry VTT version.
* Steps to reproduce the problem, and any errors from the browser console (F12).

Issues with the base DCC system (rolls, core sheets, combat) belong in the [DCC system issue tracker](https://github.com/foundryvtt-dcc/dcc/issues) instead.
