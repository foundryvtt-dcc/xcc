# Importing a Character

XCC replaces the DCC system's **Import Actor** button in the Actor Directory (right-hand sidebar, Actors tab) with its own import dialog that understands XCrawl characters.

Supported input:

* **Purple Sorcerer plain text** stat blocks — both 0-level and upper-level characters. Paste the text into the dialog; multiple characters in one paste are split and imported individually.
* **Purple Sorcerer JSON** 0-level characters.

Imported characters arrive with their occupation, stats, and equipment (with prices) filled in. For upper-level characters, assign the matching XCC class sheet afterwards via **Sheet Configuration** — see [Character Classes](Character-Classes.md).
