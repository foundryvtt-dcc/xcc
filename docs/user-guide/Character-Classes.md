# Character Classes

XCC provides a dedicated actor sheet for each XCrawl class. Create a *Player* actor as usual, then open **Sheet Configuration** (the cog in the sheet's header) and pick the XCC sheet matching the character's class — each sheet adds an **Xcrawl** tab with the class's abilities, plus the Fame & Wealth rewards tracker.

## Core Classes
* XCC Athlete
* XCC Blaster
* XCC Brawler
* XCC Jammer
* XCC Messenger

## Demi-Humans
* XCC Dwarf
* XCC Gnome
* XCC Half-Elf
* XCC Half-Orc

## Specialists
* Acrobat
* Commando
* Criminal
* Crypt Raider
* Dwarf Mechanic
* Elf Trickster
* Half-Orc Slayer
* Halfling Rogue
* Scout

## 0-Level Characters
Use the **XCC 0-Level** sheet for unclassed funnel characters.

The class descriptions, benefits, restrictions, and Mojo powers shown on the Xcrawl tab link into the XCrawl Classics Core Book module, so that module must be installed and enabled for the links to resolve.
