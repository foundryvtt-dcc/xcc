# Mojo

## Overview
Mojo is XCrawl's version of the DCC system's [Fleeting Luck](https://foundryvtt-dungeon-crawl-classics-user-guide.readthedocs.io/en/latest/Fleeting-Luck/). While the XCC module is active, Mojo is always enabled — the DCC system's *Enable Fleeting Luck* setting is ignored — and the whole Fleeting Luck dialog vocabulary is relabeled to Mojo.

Mojo works on a per-**player** basis, not per-actor. If a player has multiple actors, they still only have one "stack" of Mojo. The player avatar in the dialog is based on the user's avatar; clicking it opens the User Configuration dialog to allow quickly setting it.

The Mojo tracker lives in the **XCC Tools** sidebar tab — click the X near the bottom of the right-hand sidebar tab bar, then click the **Mojo** button to open the tracker.

Mojo is automated by default: all players' Mojo is cleared on a natural 1, and the rolling player gains a point on a natural 20. GM users are ignored for automation purposes. Automation can be turned off with the *Automate Mojo* module setting.

## Player View
For the player, the dialog presents the amount of Mojo each player has. The filter button in the top left switches between ALL players and just the logged-in player. Click the spend button to spend Mojo — you will get a dialog allowing you to choose how much to spend, and a chat message reports the player and the amount spent.

## Judge View
For the Judge, the dialog allows you to reset all players to 1 Mojo, take away all Mojo, or award or reduce an individual player's Mojo. The poker chips icon allows you to spend it on behalf of a player too.

Changes to Mojo are logged to the chat.

You can also award Mojo by right-clicking a player in the User List at the bottom left of the screen.
